# Лендінг BudPro (Payload-стиль + Vite-сторінка)

Публічна сторінка системи планування, контролю та супроводу будівельних проєктів.

## Структура

- `cms/` — API контенту (у звіті — Payload CMS 3 на Next.js; тут спрощений сервер для локального показу)
- `frontend/` — сторінка відвідувача: блоки Hero, Features, Projects, Testimonials, Contacts

## Запуск

```bash
# термінал 1 — API на порту 3000
node cms/src/server.js

# термінал 2 — сторінка на порту 5174
npx --yes serve frontend -p 5174
```

Відкрийте http://127.0.0.1:5174/

Панель редактора в повній Payload-версії: http://127.0.0.1:3000/admin
