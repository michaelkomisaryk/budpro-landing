# Лендінг БудПроєкт

Публічна сторінка до Django-системи **БудПроєкт** (планування, контроль і супровід будівельних проєктів).

Репозиторій облікової системи: https://github.com/michaelkomisaryk/budpro

## Запуск

```bash
node cms/src/server.js
npx --yes serve frontend -p 5174
```

- API: http://127.0.0.1:3000/
- Сторінка: http://127.0.0.1:5174/
